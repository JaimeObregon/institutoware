# Conservación de Arkaful

Las cuatro copias locales examinadas (A, B, C y D) contienen el mismo
`ARKAFUL.EXE`, idéntico byte a byte al que ya estaba publicado aquí.
El fichero de récords identifica el juego como Arkaful v0.99ß.

`ARKAFUL.HIS` es la tabla de récords de A y B, fechada el 12 de abril de
1998. Ya estaba publicada. `_archive/ARKAFUL.HIS` conserva la tabla distinta
de C y D, fechada el 4 de marzo de 1998. Esta diferencia refleja partidas,
no una versión diferente del programa.

No se encontró código fuente en estas cuatro copias. Los ficheros originales
se conservan sin modificaciones de contenido ni de codificación.
